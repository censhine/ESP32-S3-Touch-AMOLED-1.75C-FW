# Source provenance

The application base is Waveshare's ESP32-S3-Touch-AMOLED-1.75 repository:

- Repository: https://github.com/waveshareteam/ESP32-S3-Touch-AMOLED-1.75
- Verified revision: `e4344e70c2fa78a13e8a06566507f1ba8af6672a`
- Application path: `firmware/brookesia/` (293 files verified against Git blob hashes before adaptation).
- Framework and SquareLine paths: `examples/esp-idf/03_esp-brookesia/components/`.
- Local source ZIP SHA-256: `8cd53e84bb098aa3fd00e0bca02bdead57a62fac31302ae558f465c890248767`.
- The official firmware guide identifies its delivered image as 260805, built with ESP-IDF 5.5.4. This port builds with the installed patch release 5.5.5.

C-board hardware/BSP/schematic references:

- https://github.com/waveshareteam/ESP32-S3-Touch-AMOLED-1.75C
- Verified revision: `6d19f7e16fb9a3be219e9eed43ca9eb56c88d01c`.
- https://docs.waveshare.net/ESP32-S3-Touch-AMOLED-1.75C

- https://docs.waveshare.net/ESP32-S3-Touch-AMOLED-1.75C/XiaoZhi_AI

This is a functional port of the complete non-C application sources, not a claim that the old C-board eight-app factory source was recovered. `docs/upstream/` retains the original non-C documentation for attribution/history; its SD-card wiring, partition layout and flash instructions do not apply to this port.

The Brookesia core is the matching non-C `0.6.0-beta2`, using LVGL 9.4.0. Registry dependencies are recorded in `firmware/dependencies.lock`. Local BSP names retain `1_75` for source compatibility; the actual GPIO definitions and hardware capabilities have been changed for 1.75C. The enhanced Waveshare audio BSP was kept because the source apps need its TDM, ownership and cleanup APIs.

The original Round Wing game sources, artwork and adapter were developed in the local `round-wing-game` project. The CJK subset fonts retain their original OFL license under `assets/`. Upstream license files and copyright notices are preserved in each imported component. The root LICENSE is the Waveshare upstream license, and individual components/fonts carry their own notices.

The MusicPlayer GUI includes the LVGL music demo adapted by the Waveshare source. Its MIT notice is included at `firmware/components/MusicPlayer/gui_music/LICENCE.txt`, copied from the pinned LVGL 9.4.0 dependency. The root Apache license does not replace this notice.

Initial media consists of synthetic waveforms, baseline JPEG test patterns and a short MJPEG/PCM AVI generated by the attributed upstream helper. No third-party songs, photos or films are included.
