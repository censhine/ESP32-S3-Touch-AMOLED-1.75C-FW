# 差异清单：1.75源码、1.75C硬件与新整合工程

这里有两个比较对象：硬件表比较1.75与1.75C；应用和使用体验表比较你当前的1.75C工厂固件与新工程。新工程保留Brookesia桌面架构和原8类应用的对应功能，应用实现来自可获得的1.75源码。旧C工厂完整应用源码没有拿到，因此无法保证界面、版本及所有细节完全相同。

## 1. 硬件差异及处理

| 项目 | 1.75源码对应硬件 | 你的1.75C | 新工程处理 |
|---|---|---|---|
| Flash容量 | 16MB | 32MB | 已改32MB配置，重新分区 |
| LCD复位脚 | GPIO39 | GPIO1 | 已改驱动 |
| 触摸复位脚 | GPIO40 | GPIO2 | 已改驱动 |
| 音频主时钟MCLK | GPIO42 | GPIO16 | 已改驱动，保留双麦克风/回声参考音频逻辑 |
| PWR键 | 扩展器EXIO4 | GPIO3，按下为高电平 | 已改直接GPIO读取与按键测试 |
| TCA9554扩展器 | 有 | 无 | 已移除相关访问和依赖 |
| SD卡 | 有，使用GPIO1/2/3 | 无；这些脚用于复位和按键 | 已移除SD驱动，防止引脚冲突 |
| 媒体存储 | 主要依赖SD卡 | 可用片内Flash | 已实现16MiB内部媒体文件系统 |

共同硬件包括ESP32-S3R8、8MB PSRAM、466×466圆形CO5300屏幕、CST9217触摸、QMI8658、AXP2101和ES8311/ES7210。保留相应驱动与音频增强接口，核对了功放3.3V模型及充电配置。共用芯片型号不等于已经实测通过：触摸方向、运动轴方向、音频通道和电池状态仍需真机检查。

## 2. 原8个应用的对应关系

| 你当前的应用 | 新工程对应应用 | 已纳入内容与可能变化 |
|---|---|---|
| 设置 | Settings | Wi-Fi、亮度、音量、电源信息等；新增内部媒体管理，菜单样式以1.75源码为准 |
| 音乐 | MusicPlayer | 保留播放功能，支持内部媒体中的MP3/WAV及固件资源回退 |
| 计算器 | Calculator | 对应计算器功能，采用1.75源码版本 |
| SquareLine | SquareLine | 对应界面演示，控件和样式可能不同 |
| 重力球/Qmi8658Ball | Gravitysphere | 对应QMI8658重力球，含校准；名称和画面可能不同 |
| 频谱分析 | SpecAnalyzer | 对应麦克风频谱功能；声音输入效果待真机验证 |
| 小智机器人 | AIChats | 使用桌面内整合的小智实现，启用中文；不同于旧工厂的独立小智固件 |

以上8项是源码已纳入和功能对应，不能据此宣称与原版本完全等价或已经在实物上正常运行。

## 4. 系统与使用体验差异

| 项目 | 新工程的变化及影响 |
|---|---|
| 桌面框架 | 使用Brookesia桌面和正常应用生命周期；来自1.75源码的重新构建，部分图标、名称、界面会变化 |
| 安装方式 | 属于完整固件整合，需要安装整机候选固件；当前没有Android那样独立安装APK的机制 |
| 小智架构 | 在桌面内运行；旧独立小智的OTA分区/升级包不适用。当前未实现整机OTA升级写入器 |
| 语言 | AIChats启用中文，游戏包含中文界面；其他应用仍有上游英文标签，尚未统一全中文化 |
| 分区 | 8MiB整机程序＋6MiB字体/资源＋16MiB媒体，另有语音模型和配置区；与旧工厂布局不兼容 |
| 配置迁移 | 保留原NVS区域地址，不自动擦除；旧配置格式和云端绑定兼容性仍待验证，可能需要重新配网或激活 |
| 媒体容量 | 内部媒体16MiB，扣除文件系统和现有文件后更少；24kHz、16位双声道录音的理论总时长不足3分钟 |
| 媒体导入 | 目前在Mac离线打包成media.bin；未提供USB磁盘拖拽或网络上传界面 |
| 视频支持 | MJPEG AVI，最大466×466，显示最高10fps；不能当作通用MP4/H.264播放器 |
| 媒体更新 | 普通固件烧录清单不包含media.bin；首次初始化或主动替换media.bin会替换整区素材、录音和记录 |
| 故障处理 | 配置初始化失败不自动擦除NVS；媒体挂载失败不自动格式化 |
| 调试接口 | 改用Type-C连接可用的USB Serial/JTAG日志接口 |
