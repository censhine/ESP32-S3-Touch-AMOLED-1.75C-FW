# B0003《小种子的早晨》媒体导入

适用设备：ESP32-S3-Touch-AMOLED-1.75C。

## 图片与阅读

导入包 `B0003-device.zip` 包含 13 页中英双语图片，目标路径为 `/media/pictures/B0003001.JPG` 至 `/media/pictures/B0003013.JPG`。每张都是 460×460、RGB、baseline JPEG，文字已合成在图片中，离线即可阅读。

进入 Gallery（相册），找到 `B0003001.JPG`。点一下或向左滑动翻到下一页，向右滑动返回上一页；长按可切换 4 秒自动轮播。相册按名称排序，绘本末页后可能进入其他图片。

本包仅包含图片。`media.json`、`manifest.json` 和 `IMPORT.md` 用于电脑端校验，不需要写进媒体分区，也不会启用朗读或背景音乐。

## 导入要求

1. 读取并独立校验设备当前完整 32 MiB Flash，核对实际分区表。
2. 校验 FAT/WL 状态，提取全部原媒体文件及目录，保存文件哈希与 FAT 元数据。
3. 将 13 张图片合并到 `pictures/` 这一层；同名同内容直接保留，不同内容则停止。相册数量不能超过 128 张，空间必须足够。
4. 使用项目 `firmware/tools/pack_media.py` 打包，恢复旧文件的名称、属性和时间；保留新分配的簇编号。
5. 分别用 PyFat 与 ESP-IDF 提取工具验证新镜像，确认旧文件内容和元数据全部保留，新增文件与包内清单一致。
6. 只写实际分区表确认的媒体区域；完整回读媒体镜像，并校验固件和配置所在的其他区域保持原样，再重启设备。

备份、个人媒体及校验中间文件保留在本地被 Git 忽略的 `artifacts/` 中。
