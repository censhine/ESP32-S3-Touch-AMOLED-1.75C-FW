# 绘本图片导入与保留已有媒体

适用设备：ESP32-S3-Touch-AMOLED-1.75C，已安装本项目的 Gallery 与内部 FAT/WL 媒体分区。

## 阅读方法

在 Gallery（相册）中找到 `STORY01.JPG`，即可阅读《慢慢走，也能到》。共 12 页，文件名连续至 `STORY12.JPG`。

- 点一下或向左滑动：下一页；向右滑动：上一页。
- 长按：开启或关闭每 4 秒翻页的自动轮播。

图片已包含中文文字，离线即可阅读。本次导入仅包含图片；不会增加朗读或背景音乐功能。相册中仍有原有图片，翻过绘本末页可能进入其他图片。

## 安全导入流程

USB 串口不提供磁盘拖拽，不能将 ZIP 或 HTML 直接复制到设备。本项目 `firmware/tools/pack_media.py` 生成的是整个媒体分区镜像，因此必须合并旧文件后再打包。

1. 核实芯片身份，读取当前完整 32 MiB Flash，并用设备端独立摘要校验备份。
2. 从备份解析并验证实际分区表。只有确认 `media` 是从 `0x01000000` 开始的 16 MiB FAT 分区，才使用此布局。
3. 校验两份 WL 状态、配置与记录 CRC；按 WL 地址映射恢复 FAT，并与 SDK 解包结果比对。状态不一致时先解决恢复问题，不直接打包覆盖。
4. 提取全部文件和空目录，记录路径、大小、SHA256、FAT 名称及属性/时间信息；核对 FAT 两份表、簇链及已分配空间。
5. 将 12 张 baseline RGB JPEG 合并到 `pictures/` 这一层。遇同名文件先比较内容；不同则停止处理，不能覆盖。Gallery 不递归扫描子目录。
6. 使用 ESP-IDF 5.5.3 的项目工具打包。该工具会规范化名称并重置元数据，如需完整保留，应从旧目录项恢复原名称、属性、时间，保留新分配的簇编号；长文件名及其短名校验必须一致。
7. 再次解包新镜像。旧文件的哈希和元数据必须一致，新增文件必须正好等于导入清单；核对容量以及全部 JPEG 可解码。
8. 只写入已核实的媒体分区。回读媒体并逐字节比较，另行校验下方 16 MiB 不变，再重启检查挂载和应用启动。

备份、个人录音、媒体镜像和本地文件清单存放在被 Git 忽略的 `artifacts/`，不上传仓库。
