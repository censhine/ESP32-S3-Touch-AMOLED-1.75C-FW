## 布局参考（466×466）
SVG设计采用360×360逻辑坐标，再等比放大到466×466。
- 状态栏：x约118、y35、宽230、高36。Wi-Fi中心约(145,52)，状态文本中心约(242,60)，图标与文字单独占位。
- 猫咪：约x93、y85起，绘图区280×224。保留耳朵、表情及少量歪头运动余量。
- 正文：字体约24px，三行基线约325、357、390px，行距约32px；正文放在圆屏内部安全弦宽中。正文区不与猫脸或底部指示点重叠。
- 页面指示点：y约418，仅在长回复分页时显示；图稿为多页示例。
- 长回复按句/实际字宽分段，不截断或缩成小字。字幕逐页稳定显示，不连续自动滚动；优先与播报语句同步翻页，暂停/触摸回看细节待实现阶段设计。
- Wi-Fi断线显示对应图标与简短状态；长状态文字转为简短顶栏状态，详细说明在正文展示，避免跑马灯。

## 表情与动效提案
六种基本状态：认真听、想一想、说给你听、好开心、有点好奇、困困了。
瞳孔小范围快速移位后停留，偶发眨眼；不持续转圈。思考时抬眼轻歪头；讲话时嘴型开合，状态文字保持稳定。
motion-study.gif是5.6秒设计动效草图，用来确认方向，非设备性能验证或语音口型同步实测。
实际渲染技术、帧率、资源预算需要在用户确认后评估；不承诺当前硬件已实现这些效果。
